
# Instructions for AI Assistants

## Project
Build a simple Breaking Move Library.
Follow SPEC.md.
Never edit SPEC.md.

## Technology
- Use only HTML, CSS and JavaScript.
- No frameworks or external libraries.
- Use index.html, style.css and script.js.

## Code Style
- Write simple beginner-friendly code.
- Use const and let, not var.
- Use simple functions, loops and if statements.
- Use addEventListener for buttons.
- Add short comments to explain the code.
- Avoid complex or advanced JavaScript.

## Workflow
- Implement only one step at a time.
- Do not add unrequested features.
- Explain changes in simple language.
- Tell me how to test each step.
- Update PROGRESS.md after each completed step.
