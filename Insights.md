# Learning Insights – Breaking Move Library

## Step 1 – HTML Structure

### What was new to me
- Planning a website using a specification before writing code.

### New things I did learn
- HTML defines the structure of a website.
- Dropdown menus can be created using `<select>`.
- HTML elements can be accessed later using JavaScript.

## Step 2 – CSS Styling

### What was new to me
- Using GitHub Copilot to improve the design without changing the HTML.

### New things I did learn
- CSS controls colors, spacing and layout.
- HTML and CSS have different responsibilities.
- Copilot can modify individual files based on specific instructions.

## Step 3 – JavaScript Array

### What was new to me
- Storing multiple Breaking moves as objects inside an array.

### New things I did learn
- Arrays can store multiple objects.
- Objects contain properties such as name, category and difficulty.
- `console.log()` helps to check data in the browser console.

## Step 4 – Filtering

### What was new to me
- Filtering an array based on user selections.

### New things I did learn
- JavaScript can read selected values from dropdown menus.
- `for` loops can check multiple objects.
- `if` statements can identify matching moves.
- `addEventListener()` can react to a button click.

## Step 5 – Dynamic Results

### What was new to me
- Generating HTML content dynamically using JavaScript.

### New things I did learn
- `document.createElement()` creates new HTML elements.
- `appendChild()` adds elements to the website.
- JavaScript can update results without reloading the page.
- Previous results must be cleared before new ones are displayed.

## General Reflection

This project helped me understand how HTML, CSS and JavaScript work together.

I also learned how to work with GitHub Copilot step by step instead of asking it to build the whole website at once.

Using small tasks, testing the results and creating Git commits made the development process easier to understand.
