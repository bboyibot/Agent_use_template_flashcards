# Breaking Move Library

## About the Project

Breaking Move Library is a simple interactive website that helps Breaking dancers find moves based on their category and difficulty level.

The website was created as part of the Introduction to Programming course at USTP.

## Features

- Select a Breaking category: Toprock, Footwork, Powermoves or Freezes.
- Select a difficulty level: Beginner, Intermediate or Advanced.
- Click "Find Moves" to display matching movements.
- View the move name, category, difficulty and description.
- Display "No moves found" if no matching movements are available.

## Technologies

- **HTML:** Creates the structure of the website.
- **CSS:** Defines the design and layout.
- **JavaScript:** Stores the Breaking moves, filters them and dynamically updates the results.

## How to Use

1. Open `index.html` in a web browser or use Live Server in VS Code.
2. Select a Breaking category.
3. Select a difficulty level.
4. Click "Find Moves".
5. The matching Breaking moves will appear below the button.
